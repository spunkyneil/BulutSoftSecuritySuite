# Privacy Policy

BulutSoft Security Suite runs locally on your Windows computer.

- It does not send any data to the developers and contains no telemetry or analytics.
- Scan results, reports and logs are stored only on your computer.
- Optional features contact third parties only when you enable and start them:
  AI-assisted analysis (Anthropic API, using your own API key), public IP checks
  (e.g. ipify, Cloudflare, ipwho.is), and notifications to webhooks or Telegram bots you configure.
  Only the data the feature needs is sent (for example a scan summary or your public IP address).
- Contact: bulutsoftsecurity@info.com
